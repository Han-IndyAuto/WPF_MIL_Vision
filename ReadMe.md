---

## 📅 2025년 11월 24일
**작성자:** indy  
**검토자:** indy

### 1. 개요
- WPF 기반 MIL 라이브러리를 이용하여 영상처리 프로그램 개발 진행

### 2. 진행 내용
- GMF (Geometric Model Finder) 알고리즘에서 속성 관련 일부를 UI에서 조절할 수 있도록 수정.
- 모델 이미지를 불러와 등록 후 검사 대상 이미지를 불러와 실행 했을 때 한번에 안되는 문제 해결.
	MIL.MmodFind() 함수 수행 전에 MIL.MmodPreprocess() 함수 한번 더 호출하여 문제를 해결 
    => 해당 함수가 TrainGmfModel()함수에서도 호출되는데, ProcessImage()함수에서도 한번 더 호출하는 이슈가 있음.
- 위 문제를 해결하기 위해 MIL.MmodPreprocess() 함수 호출 전에 모델에 대한 정의 부분을 TrainGmfModel() 함수에서 적용하도록 하였으나, 검출안되는 문제가 발생.
- UI 위치 일부 수정.
   M_SMOOTHNESS 속성만 모델 등록 항목에 있었으나, M_DETAIL_LEVEL, M_SPEED 속성을 아래에서 위로 올림. => 위 문제로 별 의미 없음.
